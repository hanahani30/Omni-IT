💻 Windows

نظام تشغيل من شركة Microsoft يُستخدم على الحواسب الشخصية والمكتبية

📋 الوصف

Windows هو النظام الأكثر استخداماً عالمياً للحواسب الشخصية والمؤسسات، ويتمتع بواجهة مستخدم سهلة والعديد من التطبيقات المتاحة.

🔧 أوامر شائعة

  • dir — عرض ملفات المجلد الحالي
  • ipconfig — معلومات إعدادات الشبكة
  • ping <host> — اختبار الاتصال
  • powershell — فتح بيئة PowerShell

⚙️ لوحة التحكم والإعدادات

  • افتح لوحة التحكم: Win + R ثم اكتب control
  • افتح الإعدادات: اضغط Win + I
  • إعدادات الشبكة: الإعدادات → الشبكة والإنترنت

💡 أمثلة عملية

ipconfig /release
ipconfig /renew
Get-ComputerInfo
