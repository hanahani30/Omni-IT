⚡ C++

الوصف: لغة برمجة سريعة جداً وقوية، تُستخدم في الألعاب والتطبيقات عالية الأداء.

مثال بسيط:

#include <iostream>
using namespace std;

int main() {
    cout << "مرحباً في C++" << endl;
    return 0;
}

الاستخدامات: الألعاب، البرامج عالية الأداء، أنظمة التشغيل، الرسومات.
