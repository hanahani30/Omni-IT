مقدمة عن Go

Go (لغة البرمجة المطورة من Google) هي لغة برمجة حديثة مصممة للأداء العالي والبساطة. تُستخدم لبناء خوادم سريعة وتطبيقات الحوسبة السحابية والأنظمة الموزعة.

البرنامج الأول - Hello World

package main

import "fmt"

func main() {
    fmt.Println("مرحباً في Go!")
}

النتيجة:
مرحباً في Go!

شرح الكود:
├─ package main : الحزمة الرئيسية
├─ import "fmt" : استيراد حزمة الطباعة
└─ func main() : دالة البرنامج الرئيسية

المتغيرات والدوال

package main

import "fmt"

// متغيرات عام (global)
var globalVar = "متغير عام"

func main() {
    // متغيرات محلية
    name := "أحمد"
    age := 25
    height := 1.75
    
    fmt.Println("الاسم:", name)
    fmt.Println("العمر:", age)
    fmt.Println("الطول:", height)
    
    // استدعاء دالة
    result := add(10, 20)
    fmt.Println("المجموع:", result)
}

// دالة لجمع رقمين
func add(a int, b int) int {
    return a + b
}

النتيجة:
الاسم: أحمد
العمر: 25
الطول: 1.75
المجموع: 30

Goroutines - البرمجة المتزامنة

package main

import (
    "fmt"
    "time"
)

func sayHello(name string) {
    for i := 1; i <= 3; i++ {
        fmt.Println("مرحباً", name, "رقم", i)
        time.Sleep(1 * time.Second)
    }
}

func main() {
    // تشغيل بدون goroutine (متتالي)
    // sayHello("أحمد")
    // sayHello("فاطمة")
    
    // تشغيل مع goroutines (متزامن)
    go sayHello("أحمد")
    go sayHello("فاطمة")
    
    time.Sleep(4 * time.Second)
    fmt.Println("انتهى البرنامج")
}

النتيجة:
مرحباً أحمد رقم 1
مرحباً فاطمة رقم 1
مرحباً أحمد رقم 2
مرحباً فاطمة رقم 2
مرحباً أحمد رقم 3
مرحباً فاطمة رقم 3
انتهى البرنامج

🌐 استخدامات Go الواقعية

1. الحوسبة السحابية
   └─ مثال: Docker و Kubernetes
      ├─ إدارة حاويات Docker
      ├─ تنسيق الحاويات
      └─ شركات: Google, Uber, Netflix

2. خوادم الويب عالية الأداء
   └─ مثال: خادم مع 10,000 اتصال متزامن
      ├─ معالجة سريعة جداً
      ├─ استهلاك ذاكرة منخفض
      ├─ استهلاك CPU منخفض
      └─ شركات: Cloudflare, DigitalOcean

3. أدوات سطر الأوامر
   └─ مثال: Terraform و Hugo
      ├─ Terraform: إدارة البنية التحتية
      ├─ Hugo: موقع ثابت سريع جداً
      └─ Prometheus: مراقبة الأنظمة

4. الشبكات والبروتوكولات
   └─ مثال: تطوير برتوكولات جديدة
      ├─ VPN و proxy servers
      ├─ خوادم DNS
      └─ معالجات الشبكة عالية الأداء
