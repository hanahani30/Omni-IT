🐧 Linux

نظام مفتوح المصدر شائع للخوادم والبرمجة والحوسبة السحابية

📋 الوصف

Linux نظام قوي وموثوق مفتوح المصدر يوفر الحرية والمرونة، ويستخدمه الملايين من مطوري التطبيقات والشركات الكبرى.

🔧 أوامر شائعة في الطرفية

  • ls — عرض ملفات المجلد
  • cd — تغيير المجلد
  • grep — البحث داخل الملفات
  • sudo apt install <pkg> — تثبيت الحزم (Ubuntu/Debian)
  • systemctl start <service> — إدارة الخدمات

⚡ أمثلة عملية

ls -la
sudo apt update && sudo apt upgrade
df -h
sudo du -ah / | sort -rh | head -n 20
