🐍 Python

لغة برمجة قوية وسهلة التعلم

مقدمة عن Python

Python هي لغة برمجة عالية المستوى وسهلة التعلم، تتميز بصيغة واضحة وسهلة القراءة. تُستخدم في مجالات متعددة مثل تحليل البيانات والذكاء الاصطناعي وتطوير الويب.

أمر الطباعة (Print)

لطباعة النصوص والنتائج على الشاشة:

print("مرحباً في Python!")
print(123)
print("النتيجة:", 5 + 3)

الناتج:

مرحباً في Python!
123
النتيجة: 8

المتغيرات (Variables)

المتغيرات تُستخدم لتخزين القيم والبيانات:

# الأسلوب الصحيح لتسمية المتغيرات
name = "أحمد"
age = 25
height = 1.75
is_student = True

# طباعة المتغيرات
print(name)
print(age)
print(height)
print(is_student)

الناتج:

أحمد
25
1.75
True

أنواع البيانات

# String (نص)
text = "Hello"

# Integer (عدد صحيح)
number = 42

# Float (عدد عشري)
decimal = 3.14

# Boolean (صح أو خطأ)
flag = True

# List (قائمة)
fruits = ["تفاح", "موز", "برتقال"]

# Dictionary (قاموس)
person = {"name": "محمد", "age": 30}

العمليات الحسابية

a = 10
b = 3

# الجمع
print(a + b)  # 13

# الطرح
print(a - b)  # 7

# الضرب
print(a * b)  # 30

# القسمة
print(a / b)  # 3.333...

# قسمة صحيحة
print(a // b)  # 3

# الباقي
print(a % b)  # 1

# الأس
print(a ** b)  # 1000

الشروط (if)

age = 18

if age >= 18:
    print("أنت بالغ")
elif age >= 13:
    print("أنت مراهق")
else:
    print("أنت طفل")

الحلقات (Loops)

حلقة for:

for i in range(5):
    print(i)

# النتيجة: 0, 1, 2, 3, 4

# التكرار على قائمة
fruits = ["تفاح", "موز", "برتقال"]
for fruit in fruits:
    print(fruit)

حلقة while:

count = 0
while count < 5:
    print(count)
    count += 1

الدوال (Functions)

# تعريف دالة
def greet(name):
    return f"مرحباً {name}"

# استدعاء الدالة
print(greet("أحمد"))

# دالة بعدة معاملات
def add(a, b):
    return a + b

result = add(5, 3)
print(result)  # 8
