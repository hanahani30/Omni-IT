مقدمة عن الحوسبة السحابية

الحوسبة السحابية توفر خدمات وموارد حوسبية عبر الإنترنت بدلاً من تثبيتها محلياً. توفر مرونة وقابلية توسع وتقليل التكاليف.

أنواع خدمات الحوسبة السحابية مع أمثلة عملية

1. SaaS (Software as a Service) - البرامج كخدمة
   ├─ التعريف: برامج تعمل على الإنترنت
   ├─ الخصائص:
   │  ├─ لا تحتاج تثبيت محلي
   │  ├─ الوصول من أي جهاز
   │  ├─ التحديثات تلقائية
   │  └─ سهلة الاستخدام
   │
   └─ أمثلة واقعية:
      • Google Workspace (Gmail, Drive, Docs)
        - كتابة المستندات بشكل تعاوني
        - مثال: فريق يكتب تقرير مشتركاً
      
      • Microsoft 365 (Word, Excel, Outlook)
        - استخدام Office من المتصفح
        - حفظ تلقائي في OneDrive
      
      • Salesforce (إدارة علاقات العملاء)
        - تتبع المبيعات والعملاء
        - تقارير وتحليلات فورية
      
      • Slack (التواصل)
        - الرسائل الفورية الموثوقة
        - تكامل مع أدوات أخرى

2. PaaS (Platform as a Service) - منصة كخدمة
   ├─ التعريف: منصة لتطوير تطبيقات ويب
   ├─ الخصائص:
   │  ├─ بيئة كاملة للتطوير
   │  ├─ لا تحتاج إدارة خوادم
   │  ├─ قابلة للتوسع تلقائياً
   │  └─ دعم تام للمطورين
   │
   └─ أمثلة واقعية:
      • Heroku
        - تطبيق Node.js يُنشر بأمر واحد
        - يدير السيرفرات تلقائياً
      
      • Google App Engine
        - تطبيق Python يعمل على Google
        - تكييف تلقائي للحمل
      
      • Firebase
        - إنشاء تطبيق جوال في أيام
        - قاعدة بيانات جاهزة
        - مصادقة المستخدمين
      
      • AWS Elastic Beanstalk
        - نشر تطبيق PHP بسهولة
        - إدارة السعة تلقائياً

3. IaaS (Infrastructure as a Service) - بنية تحتية كخدمة
   ├─ التعريف: موارد حوسبية افتراضية
   ├─ الخصائص:
   │  ├─ خوادم افتراضية كاملة
   │  ├─ تحكم كامل على النظام
   │  ├─ إدارتك للبرامج والتطبيقات
   │  └─ دفع حسب الاستخدام
   │
   └─ أمثلة واقعية:
      • AWS EC2 (Elastic Compute Cloud)
        - خادم ويب يخدم موقع التجارة الإلكترونية
        - يزداد العدد في فترة المبيعات وينخفض بعدها
        - توفير تكاليف هائلة
      
      • Microsoft Azure Virtual Machines
        - خادم Windows Server
        - تطبيق قاعدة بيانات
        - نسخ احتياطية تلقائية
      
      • Google Compute Engine
        - خوادم معالجة بيانات ضخمة
        - تحليل البيانات الضخمة (Big Data)
      
      • DigitalOcean
        - خادم صغير لموقع شخصي
        - سهل وسعر منخفض

مقارنة بسيطة بين أنواع السحابة

┌─────────────────────────────────────────────────────┐
│                  SaaS    │   PaaS   │   IaaS       │
├─────────────────────────────────────────────────────┤
│ من يدير النظام؟                                     │
│ SaaS: المزود بالكامل                               │
│ PaaS: أنت تدير البرامج فقط                          │
│ IaaS: أنت تدير كل شيء                              │
│                                                     │
│ مثال: مدرسة تحتاج لنظام إدارة                      │
├─────────────────────────────────────────────────────┤
│ الخيار 1 (SaaS):                                    │
│ ├─ شراء برنامج مدرسي من Google Classroom          │
│ └─ البرنامج جاهز للاستخدام مباشرة                  │
│                                                     │
│ الخيار 2 (PaaS):                                    │
│ ├─ استخدام Firebase لبناء تطبيق إدارة             │
│ ├─ أنت قم بتطوير الخصائص المطلوبة                 │
│ └─ Firebase يدير الخوادم والبيانات                │
│                                                     │
│ الخيار 3 (IaaS):                                    │
│ ├─ شراء خادم من AWS                               │
│ ├─ تثبيت نظام التشغيل                             │
│ ├─ تثبيت قاعدة البيانات                           │
│ └─ تطوير البرنامج بنفسك                           │
└─────────────────────────────────────────────────────┘

فوائد الحوسبة السحابية

1. تقليل التكاليف
   └─ مثال: بدلاً من شراء خوادم بـ 10,000 دولار
      تدفع 100 دولار شهرية فقط

2. المرونة والتوسعية
   └─ مثال: موقع تجارة إلكترونية
      في الأيام العادية: 10 خوادم
      في الأعياد: 100 خادم تلقائياً

3. الوصول من أي مكان
   └─ مثال: فريق عمل موزع في عدة دول
      يستخدمون Google Workspace

4. الأمان والضمان
   └─ مثال: AWS يضمن 99.99% توفر الخدمة
      إذا توقفت الخدمة تحصل على تعويض

5. التحديثات التلقائية
   └─ مثال: Microsoft 365 يُحدّث نفسه
      دون احتياج تدخل منك
