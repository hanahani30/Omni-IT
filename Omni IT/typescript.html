مقدمة عن TypeScript

TypeScript هي لغة برمجة تبني على JavaScript وتضيف نظام الأنواع (Type System). هذا يساعد في اكتشاف الأخطاء قبل تشغيل البرنامج، مما يجعل الكود أكثر أماناً وسهولة في الصيانة.

المتغيرات والأنواع

نظام الأنواع في TypeScript:
═════════════════════════════

// متغير من نوع string
let name: string = "أحمد";

// متغير من نوع number
let age: number = 25;

// متغير من نوع boolean
let is_student: boolean = true;

// مصفوفة من الأرقام
let numbers: number[] = [1, 2, 3, 4, 5];

// مصفوفة من النصوص
let names: Array<string> = ["أحمد", "فاطمة", "علي"];

// نوع Union (أكثر من نوع)
let id: string | number = 1;
id = "ABC123"; // يقبل الآن

// any (أي نوع - تجنبه إن أمكن)
let data: any = "يمكن أن يكون أي شيء";

مثال عملي:
const displayUser = (name: string, age: number): string => {
    return `${name} عمره ${age} سنة`;
};

console.log(displayUser("أحمد", 25));
// النتيجة: أحمد عمره 25 سنة

الواجهات والفئات

الواجهات (Interfaces):
═════════════════════════════

interface User {
    name: string;
    age: number;
    email?: string; // اختياري
}

const user: User = {
    name: "أحمد",
    age: 25,
    email: "ahmed@example.com"
};

console.log(user.name); // النتيجة: أحمد

الفئات (Classes):
═════════════════════════════

class Student {
    name: string;
    age: number;
    
    constructor(name: string, age: number) {
        this.name = name;
        this.age = age;
    }
    
    getInfo(): string {
        return `${this.name} عمره ${this.age} سنة`;
    }
}

const student = new Student("فاطمة", 20);
console.log(student.getInfo());
// النتيجة: فاطمة عمره 20 سنة

💼 استخدامات TypeScript الواقعية

1. تطبيقات الويب الضخمة
   └─ مثال: Angular و React
      ├─ شركات: Google, Facebook, Netflix
      ├─ المميزات:
      │  ├─ اكتشاف الأخطاء مبكراً
      │  ├─ سهولة الصيانة
      │  └─ كود أنظف وأسهل فهماً

2. التطبيقات المحمولة
   └─ مثال: React Native
      ├─ تطبيقات iPhone و Android
      ├─ نفس الكود يعمل على المنصتين
      └─ شركات: Shopify, Slack

3. خوادم الويب
   └─ مثال: Node.js مع Express
      ├─ APIs RESTful
      ├─ خوادم GraphQL
      └─ أتمتة المهام

4. أدوات سطر الأوامر
   └─ مثال: VS Code
      ├─ أداة webpack
      ├─ أداة TypeScript الأساسية
      └─ أدوات بناء (Build Tools)
