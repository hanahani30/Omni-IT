مقدمة عن إدارة الشبكات

مسؤول الشبكة مسؤول عن تثبيت وتكوين وصيانة وأمان الشبكات. يجب أن يكون لديه معرفة عميقة بأجهزة الشبكة والبرامج والبروتوكولات.

مهام مسؤول الشبكة مع أمثلة عملية

1. التثبيت والتكوين الأولي
   └─ أمثلة واقعية:
      • تثبيت جهاز موجه جديد (Router)
        - توصيل الأسلاك
        - إعدادات IP (مثال: 192.168.1.1)
        - إنشاء شبكة WiFi وكلمة مرور قوية
      
      • تكوين المحول (Switch)
        - تعيين عناوين VLAN
        - إعدادات الأمان (802.1X)
      
      • إضافة خادم جديد للشبكة
        - تثبيت نظام التشغيل (Windows Server/Linux)
        - تثبيت DHCP و DNS
        - ربط معلومات المستخدمين (Active Directory)

2. المراقبة والصيانة اليومية
   └─ أمثلة واقعية:
      • فحص صحة الشبكة
        - سرعة الإنترنت: فحص أن تكون 100 Mbps
        - استخدام النطاق الترددي
        - الأجهزة المتصلة بالشبكة
      
      • المراقبة اليومية
        - استخدام أدوات: Nagios, Zabbix
        - إنشاء تقارير عن الأداء
        - فحص استهلاك الخوادم
      
      • النسخ الاحتياطية
        - نسخ احتياطية يومية من البيانات
        - حفظ في موقع آمن (خادم احتياطي)
        - اختبار استعادة البيانات شهرياً

3. حل المشاكل والصيانة الوقائية
   └─ أمثلة واقعية:
      • الاتصال لا يعمل
        - فحص الكابل (Ethernet)
        - إعادة تشغيل جهاز الموجه
        - فحص عنوان IP
        مثال: ping 192.168.1.1
      
      • الإنترنت بطيء جداً
        - فحص استخدام النطاق الترددي
        - البحث عن البرامج التي تستهلك الإنترنت
        - عزل الجهاز المصاب
      
      • أجهزة لا تجد الشبكة
        - فحص خادم DHCP
        - فحص تكوين الجهاز
        - إعادة تشغيل بطاقة الشبكة

4. إدارة المستخدمين والصلاحيات
   └─ أمثلة واقعية:
      • إضافة مستخدم جديد
        - إنشاء حساب على الخادم (AD)
        - تعيين الأجهزة المسموح له بالوصول
        - تحديد كلمة مرور قوية (ملزمة في كل 90 يوم)
      
      • إزالة موظف قديم
        - حذف الحساب من النظام
        - استرجاع الأجهزة المحمولة
        - نقل البيانات إلى موظف جديد
      
      • إدارة الصلاحيات
        - موظف التسويق: وصول لمشاركة المبيعات فقط
        - موظف تقني: وصول كامل للخوادم
        - مدير: وصول لجميع الموارد

5. الأمان والحماية
   └─ أمثلة واقعية:
      • جدار الحماية (Firewall)
        - السماح بـ HTTP/HTTPS من الخارج
        - حجب جميع المنافذ الأخرى
      
      • مكافحة الفيروسات
        - تثبيت على جميع الأجهزة
        - تحديث يومي للتعريفات
        - فحص شامل أسبوعي
      
      • VPN للموظفين البعيدين
        - الوصول الآمن للشبكة من المنزل
        - تشفير كامل للبيانات
        - مثال: مستخدم يعمل من البيت يتصل عبر VPN

أدوات مهمة لمسؤول الشبكة

1. أدوات التشخيص والاختبار
   ├─ ping: فحص الاتصال بجهاز آخر
   │  مثال: ping 8.8.8.8
   │
   ├─ ipconfig (Windows) / ifconfig (Linux)
   │  عرض معلومات الشبكة
   │
   ├─ tracert: تتبع المسار إلى الخادم
   │  مثال: tracert google.com
   │
   └─ netstat: عرض الاتصالات النشطة

2. أدوات إدارة الشبكات
   ├─ Cisco IOS: لإدارة أجهزة Cisco
   ├─ Windows Server: لإدارة الخوادم
   └─ Linux (Ubuntu/CentOS): لخوادم مفتوحة المصدر

3. أدوات المراقبة
   ├─ Nagios: مراقبة شاملة لأداء الشبكة
   ├─ Zabbix: تجميع ومراقبة البيانات
   ├─ Wireshark: تحليل حركة البيانات
   └─ PRTG: مراقبة النطاق الترددي

4. النسخ الاحتياطي
   ├─ Backup software: Veeam, Acronis
   └─ Cloud backup: Google Drive, OneDrive
