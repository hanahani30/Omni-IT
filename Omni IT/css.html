مقدمة عن CSS

CSS (Cascading Style Sheets) هي لغة لإضافة التنسيقات والألوان والحركات لصفحات الويب، تُستخدم مع HTML لإنشاء صفحات جميلة واحترافية.

المحددات (Selectors)

/* محدد العنصر */
p {
    color: blue;
}

/* محدد الفئة (Class) */
.highlight {
    background-color: yellow;
}

/* محدد الهوية (ID) */
#header {
    color: white;
}

/* محدد الخاصية */
input[type="text"] {
    border: 1px solid gray;
}

الألوان والخطوط

/* الألوان */
.red-text {
    color: red;                    /* اسم اللون */
    color: #FF0000;                /* Hex */
    color: rgb(255, 0, 0);         /* RGB */
}

/* الخطوط */
body {
    font-family: Arial, sans-serif;
    font-size: 16px;
    font-weight: bold;
    line-height: 1.6;
}

نموذج الصندوق (Box Model)

/* الهامش والحشو والحدود */
.box {
    margin: 20px;           /* هامش خارجي */
    padding: 15px;          /* حشو داخلي */
    border: 2px solid blue; /* حد */
    width: 200px;           /* العرض */
    height: 100px;          /* الارتفاع */
}

Flexbox (الصناديق المرنة)

.container {
    display: flex;
    justify-content: center;  /* محاذاة أفقية */
    align-items: center;      /* محاذاة عمودية */
    gap: 20px;               /* المسافة بين العناصر */
}

.item {
    flex: 1;  /* توزيع متساوي */
}

CSS Grid (الشبكة)

.grid {
    display: grid;
    grid-template-columns: 1fr 1fr 1fr;  /* 3 أعمدة متساوية */
    gap: 15px;                           /* المسافة بين العناصر */
}

.grid-item {
    background-color: #3498db;
    padding: 20px;
}

الحركات والتأثيرات

/* Transition (انتقال سلس) */
.button {
    background-color: blue;
    transition: background-color 0.3s ease;
}

.button:hover {
    background-color: red;
}

/* Keyframes (حركة معقدة) */
@keyframes slide {
    from {
        transform: translateX(0);
    }
    to {
        transform: translateX(100px);
    }
}

.animated {
    animation: slide 2s infinite;
}

التصميم المتجاوب (Responsive Design)

/* للشاشات الكبيرة */
.container {
    width: 1200px;
}

/* للشاشات المتوسطة */
@media (max-width: 768px) {
    .container {
        width: 100%;
        padding: 20px;
    }
}

/* للشاشات الصغيرة */
@media (max-width: 480px) {
    .container {
        padding: 10px;
    }
}
